A quick reference document for transliterating Indic languages. This reference is for the macOS; Linux has a much more intuitive input using the Compose key (I don't use Windows; if you are referring to this for Windows, you're out of luck). This page contains letters from two of the scripts that I am familiar with, and covers all sounds in the various languages I speak and write.

## Diacritic Key Combinations

| Diacritic       | Meaning                          | macOS Option Key Combo      | Example |
| --------------- | -------------------------------- | --------------------------- | ------- |
| Macron ( ¯ )    | Long Vowel                       | Option + a → Letter         | ā       |
| Underdot ( . )  | Retroflex / Vocalic / Visarga    | Option + x → Letter         | ṭ       | ḥ |
| Underline ( _ ) | Alveolar / Special Tamiḻ Liquids | Option + h → Letter | ṟ       | ḻ |
| Overdot ( ˙ )   | Velar Nasal                      | Option + w → n              | ṅ       |
| Tilde ( ~ )     | Palatal Nasal                    | Option + n → n              | ñ       |
| Acute ( ´ )     | Palatal Sibilant                 | Option + e → s              | ś       |
